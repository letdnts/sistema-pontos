# 🧠 Routine Points System

A simple system to track daily tasks using points, helping improve consistency and motivation.

---

## ✨ Features

* Mark completed tasks
* View daily points and progress
* Calendar navigation by date
* Monthly earnings estimate (based on points)
* Task management (add, edit, delete)
* Automatic saving with `localStorage`

---

## 📁 Structure

```id="k2m9sd"
sistema_de_pontos_rotina.html   # Main page
tarefas_banco.html             # Task management
sistema_de_pontos_rotina.css   # Styles
```

---

## 🚀 How to Use

1. Open `sistema_de_pontos_rotina.html`
2. Mark your daily tasks
3. Track your points and progress
4. Use “Manage tasks” to edit tasks

---

## ⚠️ Notes

* Frontend only (no backend)
* Data is stored locally
* Clearing browser data will erase progress

---

## 💡 Purpose

To support habit building and routine consistency through a reward-based system.
